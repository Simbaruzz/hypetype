# hypetype UI — новый интерфейс (прод)

Итог спайка UI-SPIKE.md: вердикт владельца — **(a) путь A едет в прод**.
Нативный AHK v2 Gui воспроизводит структуру macOS-версии (KeyboardEditorView2 +
TypographSettingsView). Этот документ — спека интеграции нового UI в hypetype.

## 1. Состав

| Файл | Роль |
|---|---|
| `src/editor2.ahk` | Окно-клавиатура (редактор раскладки): тёмная тема, Text-кейкапы, ховер, курсор-«рука», попап правки клавиши, подсказка по ⓘ с лого |
| `src/typograph2.ahk` | Настройки типографа — **второе состояние того же окна** (сайдбар Основные/О типографе, 19 правил, тумблеры/выпадашки) |
| `src/ui-preview.ahk` | Точка входа спайка (интерпретатором, без трея). Оставлена для быстрой итерации по UI |
| `assets/logo.png`, `assets/lion.png` | Лого в хинт-зоне (рендер из `_SVG/*.svg`: Chrome headless, 96px, прозрачный фон) |

Старый `src/editor.ahk` удалён — заменён editor2 полностью.

## 2. Одно окно, три состояния

1. **Клавиатура** — редактор раскладки. ⓘ раздвигает окно подсказкой и лого.
2. **Попап правки клавиши** — модальный (Disable владельца + click-through вуаль).
3. **Настройки типографа** — по клавише ТИПОГРАФ; те же Gui/hwnd, переключение
   видимостью контролов + ресайз (WM_SETREDRAW на время перестройки).

Крестик: в проде **прячет** окно (программа живёт в трее), в спайке (ui-preview,
`Editor2.StandAlone := true`) — завершает скрипт. Esc в настройках возвращает
клавиатуру; повторное открытие окна всегда начинается с клавиатуры.

## 3. Настройки типографа: раздельные ключи [Typograph]

Формат ключей — общий с macOS (`TypographFormat.swift`), один config.ini:

- Кавычки: `Quotes`
- Тире: `DashText`, `DashSpeech`, `DashRanges`
- Пунктуация: `PunctEllipsis`, `PunctCollapse`, `PunctOrder`
- Пробелы: `SpaceClean`, `PercentSpace` (none|narrow|regular)
- Неразрывные: `NbspNumberWord`, `NbspInitials`, `NbspParticles`, `NbspShortWords`
- Числа: `CurrencySymbol`, `CurrencyGrouping`, `CurrencyKopecks`, `CurrencyPosition` (after|before)
- Символы: `Symbols`
- Ёфикатор: `Yo` (0 по умолчанию)

Движок `typograph.ahk` гейтит каждое под-правило своим ключом (порт ветвления из
`Typograph.swift`). Правила Win-движка, которых нет на маке, живут под ближайшим
ключом: «и т.д. / сокращения / орг-формы / висячее короткое слово» — под
`NbspShortWords`; «тыс./млн/млрд» — под `NbspNumberWord`.

**Миграция**: старые групповые ключи (`Dashes`, `Punct`, `Nbsp`, `Numbers`)
разворачиваются в раздельные при загрузке конфига (значение группы наследуют все
под-ключи), затем удаляются. Выполняется один раз, mac-версия старых ключей не
пишет.

## 4. Трей

- «Редактировать» → `Editor2.Show()` (новое окно).
- Пункт «Ёфикатор» **удалён**: состояние живёт в окне настроек типографа
  (единственный источник правды — решение владельца после рассинхрона на маке).
- Остальное без изменений (Автостарт, Виртуализация, Про hypetype, Выход).

## 5. Принятые компромиссы натива (из спайка)

- Эмодзи на кейкапах монохромные (GDI).
- Кнопки-попапы и тумблеры — плоские Text-контролы, скруглений нет (вердикт: ок).
- Выпадашки настроек открывают системное контекстное меню (может быть светлым).
- Лого — PNG из SVG (нативного SVG-рендера в GDI нет); при обновлении вектора
  перегенерить: Chrome headless, `--window-size=40,40 --force-device-scale-factor=2.4
  --default-background-color=00000000`.
- Слои символов кейкапов — шрифт Segoe UI Symbol (в Segoe UI нет `␣` и части глифов).

## 6. Проверено (спайк + интеграция)

- Клик любой площадью кейкапа; сохранение через попап пишет config.ini и обновляет кейкап.
- Тумблер/сохранение настроек пишут раздельные ключи; повторное открытие перечитывает конфиг.
- Один hwnd на клавиатуру и настройки; Esc/закрыть/сохранить возвращают клавиатуру; крестик закрывает приложение (спайк).
- DPI 125% — сетка не разъезжается (встроенный DPIScale v2); 100/150% — глазами владельца.
- Юнит-тесты `tests/run_tests.ahk` покрывают типограф с раздельными ключами.
