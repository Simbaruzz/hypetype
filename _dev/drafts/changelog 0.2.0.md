# Changelog

## 0.2.0

Большое обновление интерфейса: редактор раскладки и настройки типографа получили
новый вид, портированный с версии для macOS, единое окно вместо разрозненных
попапов и заметно более гибкие настройки типографа.

### ✨ Новое

- **Новый редактор раскладки.** Тёмная тема, клавиатура выглядит как физическая —
  клавиши-кейкапы вместо списка строк. Клавиша **ⓘ** раскрывает подсказку по
  использованию, лого в углу оживает львом при наведении и ведёт на сайт проекта.
- **Единое окно.** Настройки типографа — это второе состояние того же окна
  редактора, а не отдельный попап: `Esc` и крестик всегда возвращают туда, откуда
  логично, лишнее окно на панели задач не появляется.
- **Клик по иконке в трее открывает редактор** — не только через пункт меню, как
  раньше.
- **Настройки типографа стали намного детальнее.** Тире, пунктуация, неразрывные
  пробелы и валюта — теперь отдельные переключатели вместо одной общей галочки на
  всю группу. Появился отдельный режим пробела перед знаком процента: без пробела /
  узкий / обычный.
- **Невидимые пробелы видно.** Волосяной пробел, доля em и другие тонкие пробельные
  символы показываются прямо на клавише полоской нужной ширины, а не выглядят
  пустым местом.
- **Новый попап правки символа** в духе macOS-версии: крупная буква, подписи
  «Alt + Shift + X» / «Alt + X», подсказка со вставкой из буфера обмена (Ctrl+V).

### 🔧 Улучшено

- **Формат `[Typograph]` в конфиге переведён на раздельные ключи**, общие с
  macOS-версией раскладки. Старый (групповой) формат мигрируется автоматически при
  первом запуске, с резервной копией.
- **«Ёфикатор» убран из трей-меню** — единственный источник правды теперь галочка
  в окне настроек типографа (в меню её состояние иногда не сбрасывалось корректно).
- **Шрифт интерфейса — Segoe UI Semibold**: обычный вес смотрелся слишком тонко.
- Лого и лев теперь вшиты прямо в exe — окно редактора выглядит как надо, даже если
  exe лежит отдельно от папки `assets`.
- Формулировка «отмена» → «отменить» в попапе правки символа.
