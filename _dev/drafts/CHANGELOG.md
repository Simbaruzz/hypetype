# Changelog

Заметные изменения hypetype для Windows.

## 0.1.0

Большое обновление: hypetype полностью переписан с нуля и оброс крупными новыми
возможностями — автотипограф, ёфикатор и переключение виртуализации без ручного
перезапуска.

### ✨ Новое

- **Автотипограф.** Выдели текст в любом приложении и нажми **правый Alt + Backspace** —
  выделение заменится «причёсанным»: «ёлочки» вместо `"прямых кавычек"`, длинное тире
  вместо дефиса, неразрывные пробелы, многоточие `…`, валюта и числа (`100 руб.` →
  `100 ₽`, `109$` → `109 $`), и многое другое. Полностью офлайн, без интернета.
  Повторное нажатие безвредно, `Ctrl+Z` возвращает исходник.
- **Ёфикатор** (по желанию). Тот же автотипограф умеет расставлять «ё» в частых
  словах (`еще` → `ещё`, `самолет` → `самолёт`, `Артем` → `Артём`). По умолчанию
  **выключен**, включается одной строкой в конфиге (`[Typograph]` → `Yo=1`). Спорные
  слова-омографы (`все/всё`) не трогает.
- **Виртуализация без ручного перезапуска.** Раньше для включения нужно было закрыть
  программу и заново запустить от администратора. Теперь просто жмёшь
  «Виртуализация» — программа сама запросит права через UAC и всё сделает.
- **Мгновенное применение правок.** Поменял символ в редакторе — работает сразу, без
  перезапуска. Настройки типографа из конфига — тоже подхватываются на лету.

### 🔧 Улучшено

- **Переносимый формат конфига.** `config.ini` стал единым для Windows и macOS —
  раскладку можно копировать между устройствами. Старый конфиг мигрируется
  автоматически, с резервной копией `config.old.ini`.
- **Безопаснее с реестром.** Программа больше не перезаписывает чужие переназначения
  правого Alt: если его уже занял другой софт — вежливо откажется и ничего не сломает.
- **Чинит «настройки не сохраняются».** Если программа лежит в защищённой папке
  (например, `Program Files`), конфиг уходит в `%AppData%\hypetype` вместо тихой
  потери в VirtualStore.
- **Редактор раскладки:** одно окно правки за раз, аккуратные отступы, очистка поля
  честно очищает символ (а не подставляет пробел).
- Новый пункт меню **«Про hypetype↗»** — открывает страницу проекта.
- **Дефолтная раскладка:** `Alt + Shift + 8` → `↔`, `Alt + Space` → неразрывный пробел.
- Сборка теперь 64-битная (AutoHotkey v2).

### 🩹 Поправлено

- macOS-кавычки-«лапки» (`“ ”`) в тексте теперь корректно превращаются в «ёлочки»
  (раньше оставались и съедали соседний пробел).
- Диакритика переведена на надёжный механизм без глобальной блокировки ввода
  (`◌̌` + буква → `ǧ`).
