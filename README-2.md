## Автотипограф

Выделите текст в любом приложении и нажмите **правый Alt + Backspace** — выделение
заменится типографированным вариантом. Работает офлайн, мгновенно, в любом поле ввода
(заметки, мессенджеры, документы, браузерные формы).

Что делает:

- **Кавычки:** `"привет"` → `«привет»`, вложенные → `«сказал „да“»`. Английские/macOS
  «лапки» `“…”` тоже превращаются в «ёлочки».
- **Тире:** `гений и злодейство - две вещи` → `… — две вещи` (с неразрывным пробелом
  перед тире); диапазоны `2002-2009` → `2002–2009`.
- **Пунктуация:** `...` → `…`, лишние пробелы убираются, пробел после запятой
  добавляется.
- **Неразрывные пробелы:** после коротких предлогов/союзов, между числом и словом,
  в инициалах `А.А. Иванов` и т.п.
- **Числа и валюта:** `100 руб.` → `100 ₽`, `109$` → `109 $`, группировка разрядов
  у сумм, десятичная запятая.
- **Символы:** `(c)` → `©`, `(tm)` → `™`, `+-` → `±`.

Особенности и честные ограничения:

- **Форматирование заменённого фрагмента теряется** — вставляется обычный текст. Это
  свойство механики через буфер обмена.
- **Не применяйте к коду** — неразрывные пробелы невидимы и могут «сломать» исходники
  незаметно для глаза.
- **`Ctrl+Z`** сразу после возвращает исходный текст (обычная отмена приложения).
- **Идемпотентность:** повторное нажатие на уже типографированном тексте ничего не
  портит.
- Хоткей работает только при включённой **«Виртуализации»** (как и ввод символов).

## Ёфикатор (е → ё)

Автотипограф умеет расставлять «ё» в частых словах: `еще` → `ещё`, `самолет` →
`самолёт`, `Артем` → `Артём`.

- **По умолчанию выключен.** Чтобы включить — добавьте в `config.ini` секцию (или
  поправьте, если есть):
  ```ini
  [Typograph]
  Yo=1
  ```
  Изменение подхватывается без перезапуска.
- **Безопасно по смыслу:** трогаются только однозначные слова. Омографы, где «ё»
  меняет смысл (`все/всё`, `узнает/узнаёт`, `тема/Тёма`), **не трогаются**.
- **Ограничение словаря:** используется частотный набор (~3000 парадигм + частые
  имена). Редкие слова могут остаться без «ё» — это осознанный компромисс размера.

## Настройки `[Typograph]`

Секция в `config.ini`. Все группы включены по умолчанию; правки применяются **без
перезапуска**.

```ini
[Typograph]
Quotes=1            ; кавычки-ёлочки
Dashes=1            ; тире и диапазоны
Punct=1             ; многоточие и пунктуация
SpaceClean=1        ; чистка пробелов, пробел после запятой
Nbsp=1              ; неразрывные пробелы
Numbers=1           ; числа и валюта
Symbols=1           ; (c) (tm) +- и т.п.
Yo=0                ; ёфикатор (е -> ё), по умолчанию выключен

PercentSpace=none       ; none = 23% слитно | narrow = 23 % (узкий пробел)
CurrencyPosition=after  ; after = 109 $ | before = $ 109
```

Любую группу можно выключить (`=0`), если её правила мешают.

## Виртуализация без ручного перезапуска

Раньше: чтобы включить «Виртуализацию», нужно было закрыть программу и запустить её
от имени администратора вручную.

Теперь: просто нажмите пункт **«Виртуализация»** в трее. Если прав администратора нет,
программа сама перезапросит их через UAC, переключит виртуализацию и покажет результат.
После этого, как и прежде, нужна **перезагрузка** — Scancode Map применяется только
после неё.

Если отклонить запрос UAC — ничего не меняется, программа продолжает работать как была.

## Переносимый формат конфига

`config.ini` стал единым для Windows и macOS — раскладку можно копировать между
устройствами. Символы хранятся в виде Unicode-кодпоинтов, поэтому ни один символ
(включая `,` `|` `;`, эмодзи, диакритику) не ломает файл. К каждой строке раскладки
дописывается комментарий с «живыми» символами для читаемости.

При первом запуске старый `config.ini` (формата 0.0.x) **мигрируется автоматически**,
а его копия сохраняется как `config.old.ini`. Если папка программы защищена от записи,
конфиг создаётся в `%AppData%\hypetype`.
